# EVOLVE M1–M7 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this
> plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build EVOLVE, a deterministic artificial-life ecosystem simulator (M1–M7; M8 deferred)
with genome-derived organisms, batched evolvable neural controllers, a closed mass/energy ledger,
environmental forcing, full statistics, SQLite persistence, a Pygame view and experiments A–H.

**Architecture:** Hybrid NumPy structure-of-arrays engine (arrays authoritative, thin read-only
`OrganismView` for inspection), staged tick pipeline (read → propose → resolve → apply), uniform
spatial grid with pair expansion, single seeded RNG stream with documented draw order, dual
conservation ledger (closed mass; energy with one light input and one heat sink).

**Tech Stack:** Python 3.14, NumPy 2.5, PyYAML, Pytest; Pygame-**ce** 2.5.8 for the view (the
maintained, API-compatible fork — the only one with a Python 3.14 wheel on this machine);
Matplotlib for offline reports; SQLite for persistence.

**Spec:** `docs/PROJECT_SPEC.md` (requirements), `docs/DESIGN.md` (approved design — all formulas,
constants, gene tables, ledger rules and conflict rules live there; this plan argues from them).

## Global Constraints

- Engine (`src/evolve/*` except `viz/`) must never import pygame or matplotlib.
- Determinism: one `np.random.Generator(PCG64(seed))`; float64; fixed draw order; ties by ascending
  organism ID; no `random` module, no set/dict-order dependence in the hot path.
- No behavioural rules: the only decision points are the output thresholds in `actions.py`
  (DESIGN §5.3); `escape` may never steer; sensors never read `actions.py`.
- Conservation: mass invariant and energy invariant asserted to `rtol=1e-9` in tests (DESIGN §6.1).
- Population cap 5,000 default; births fail (parent pays nothing) when the cap is reached.
- Tests must run on a 1-core, ~1 GB machine: integration tests use the scaled-down sizes in
  `tests/conftest.py` (small world overrides) and are marked `integration`; nothing in the default
  suite may take more than ~30 s. Full-scale runs are CLI-only and documented in `BENCHMARKS.md`.
- Every task ends with a commit. No push, ever.

## Review Focus

1. **Ledger closure with every channel on** (feeding, predation, decay, germination, events): a
   channel that moves mass without moving energy (or vice versa) breaks `rtol=1e-9`. Test:
   `test_mass_and_energy_conservation_all_channels` (Task 17).
2. **Founder viability**: thresholds are fractions of `E_max`; a regression to absolute thresholds
   silently sterilises ~77 % of founders. Test: `test_no_sterile_founders` (Task 9).
3. **Escape steering**: any change of heading from the escape output is a forbidden rule. Test:
   `test_escape_does_not_steer` (Task 14).
4. **Resume equality**: snapshot at tick k + run to n must equal an uninterrupted run to n,
   including RNG state. Test: `test_resume_equals_continuation` (Task 23).
5. **Cap-reached births**: must fail with no energy paid, not queue by energy. Test:
   `test_cap_birth_fails_free` (Task 11).
